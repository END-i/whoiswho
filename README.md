# Хто є хто

Сімейна гра-розмова для телефона, який передають по колу. Працює офлайн, без бекенду, акаунтів, реклами й хмарних сервісів. Безпечна для дітей від 8 років.

- 8 категорій, 200 питань: «Вгадай», «Що про тебе знають», «Хто з нас?», «Згадай», «Скажи приємне», «Відкрийся», «Якби…», «Покажи!»
- питання про гравця ліворуч, праворуч чи на вибір; фото гравців з веселими й серйозними шаблонами
- режим з балами (за замовчуванням вимкнений), п'єдестал у підсумку
- номери карток щоразу нові: жодне питання не отримує свій номер з минулої гри
- гра зберігається сама: можна закрити й продовжити

## Вимоги

- Node.js **20.19+ або 22.12+** (Vite 8). Версія для хостингу — у `.node-version`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 і адреса в локальній мережі — відкрий на телефоні в тій самій Wi-Fi
npm run build      # збірка в dist/
npm run preview    # подивитися зібрану версію
```

## Тести

```bash
npm test               # юніт-тести (node:test)
npm run test:coverage  # те саме + поріг 100% рядків, гілок і функцій для src/lib і scripts/audio-lib.mjs
npm run test:e2e       # e2e у Playwright: Chromium (як Android) і WebKit (як Safari на iPhone)
npm run test:all       # усе разом
```

Перед першим запуском e2e: `npx playwright install chromium webkit`.

Уся логіка (перемішування, черга, бали, ролі, збереження, Wake Lock, озвучка) — чисті функції в `src/lib/` і покрита юніт-тестами повністю. Те, що юніт-тестами не перевірити (екрани, фото через canvas, localStorage, перезавантаження, вигляд на 320 px, темна тема), покрито e2e.

## Питання

Усі питання — у `src/data/questions.json`. Після зміни файлу гра сама перевірить схему й покаже зрозумілу помилку, якщо щось не так; `npm test` перевіряє справжній файл.

```jsonc
{ "id": "gs-26",              // унікальний
  "category": "guess",        // id категорії з categories[]
  "type": "guess",            // open | choice | activity | guess | who (за замовчуванням — з meta.fieldDefaults)
  "audience": "all",          // all | kids
  "answerer": "self",         // хто відповідає: self | left | right | pick
  "about": "left",            // про кого: self | left | right | pick | answerer (за замовчуванням — про того, хто відповідає)
  "text": "Що гравець ліворуч любить найбільше?",
  "tip": "Необов'язкова підказка для дорослих" }
```

Правила тексту (їх перевіряють тести):
- **без імен** і без `{…}`: роль пишемо словами — «гравець ліворуч / праворуч», «вибери будь-кого», «той, чия черга»; ім'я й фото гра покаже над карткою;
- **без форм у дужках** на кшталт «з'їв(ла)»: про інших — у чоловічому роді («гравець не з'їв би»), до тебе — безособово («Коли тобі востаннє було весело?»);
- у guess-питанні слова мають називати, про кого воно;
- у категоріях з балами (`meta.scoringCategories`) — лише `type: guess`;
- **нічого 18+**: гра сімейна. Набори для пар, дорослих і друзів — у [docs/backlog.md](docs/backlog.md).

## Озвучка (необов'язково)

Без озвучки гра працює як звичайно: питання читає хтось із гравців. Якщо для питання є файл `public/audio/{id}.mp3`, на картці з'являється кнопка «🔊». Генерація одноразова й пропускає готові файли.

### Piper — локально й безкоштовно

```bash
pip install --user piper-tts                                   # Python 3.9+
mkdir -p ~/piper && cd ~/piper && python3 -m piper.download_voices uk_UA-ukrainian_tts-medium && cd -
npm run audio -- --model ~/piper/uk_UA-ukrainian_tts-medium.onnx --speaker 2
```

ffmpeg не потрібен: WAV від Piper кодується в MP3 прямо в Node (lamejs). Якщо `piper` не в `PATH`, вкажи шлях: `PIPER_BIN=~/Library/Python/3.9/bin/piper npm run audio -- …`.

У моделі три голоси: `--speaker 0` (Лада), `1` (Микита), `2` (Тетяна — зараз у грі). Щоб перезаписати іншим: додай `--force`.

Українська модель читає текст посимвольно й знає лише малі літери, тож скрипт сам переводить текст у малі літери, числа — у слова («10 секунд» → «десять секунд»), прибирає лапки й невідомі моделі символи.

### Azure F0 — безкоштовний рівень

У `.env` (у git не потрапляє):

```
AZURE_SPEECH_KEY=...
AZURE_SPEECH_REGION=westeurope
AZURE_SPEECH_VOICE=uk-UA-PolinaNeural
```

```bash
npm run audio -- --engine azure
```

Інше: `--list` (що буде озвучено), `--force` (перегенерувати все), `--only gs-01,gs-02`. Файли — моно MP3 32 кбіт/с (Piper) чи 48 кбіт/с (Azure), 12–25 КБ на питання. Після нових питань просто запусти ще раз — готові файли пропускаються.

Якщо записаної озвучки немає, у налаштуваннях можна ввімкнути **голос браузера** — він доступний, лише якщо на телефоні є український голос.

## Встановлення на телефон

Гра — PWA: після встановлення відкривається як застосунок, без адресного рядка, і працює без інтернету.

- **iPhone (Safari):** відкрий сайт → «Поділитися» → «На початковий екран». Встановлена гра не втрачає збережених даних (Safari чистить дані сайтів, які не відкривали 7 днів, але не встановлених на екран).
- **Android (Chrome):** відкрий сайт → меню ⋮ → «Встановити застосунок» (або банер «Додати на головний екран»).

Під час гри екран не гасне (Wake Lock). Якщо телефон цього не вміє, гра підкаже вимкнути автоблокування.

## Публікація

Гра: **https://whoiswho.evgeniy-donev.workers.dev**

Хостинг — **Cloudflare Workers (Static Assets)**, підключений до репозиторію: кожен push у `main` збирає й публікує гру. Результат видно як перевірку «Workers Builds» біля коміту на GitHub (GitHub Actions не використовуються). Налаштування — у `wrangler.jsonc`:

| Що | Значення |
|---|---|
| Build command | `npm run build` (або порожньо — збірку запускає `build.command` у `wrangler.jsonc`) |
| Deploy command | `npx wrangler deploy` |
| Папка гри | `dist` |
| Node | з `.node-version` (22) |

Перевірити опубліковану версію тими самими e2e: `E2E_BASE_URL=https://whoiswho.evgeniy-donev.workers.dev npm run test:e2e`.

## Приватність

Імена, фото й прогрес зберігаються лише в браузері цього телефона (localStorage). Нічого нікуди не надсилається. «Видалити всі фото» в налаштуваннях стирає фото й шаблони.
