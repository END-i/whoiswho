# Хто є хто

Сімейна гра-розмова для телефона, який передають по колу. Працює офлайн, без бекенду, акаунтів, реклами й хмарних сервісів. Безпечна для дітей від 8 років.

- 4 набори, 904 питання: «Для сімʼї» (9 категорій, зокрема «Цікаві факти»), «Для пар», «Для друзів», «Для дорослих» (18+); українською й російською, з озвучкою
- питання про гравця ліворуч, праворуч чи на вибір; фото гравців з веселими й серйозними шаблонами
- режим з балами (за замовчуванням вимкнений), п'єдестал у підсумку
- номери карток щоразу нові: жодне питання не отримує свій номер з минулої гри
- гра зберігається сама: можна закрити й продовжити

## Вимоги

- Node.js **20.19+ або 22.12+** (Vite 8). Версія для хостингу — у `.node-version`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 і адреса в локальній мережі — відкрий на телефоні в тій самій Wi-Fi
npm run build      # збірка в dist/
npm run preview    # подивитися зібрану версію
```

## Тести

```bash
npm test               # юніт-тести (node:test)
npm run test:coverage  # те саме + поріг 100% рядків, гілок і функцій для src/lib і scripts/audio-lib.mjs
npm run test:e2e       # e2e у Playwright: Chromium (як Android) і WebKit (як Safari на iPhone)
npm run test:all       # усе разом
```

Перед першим запуском e2e: `npx playwright install chromium webkit`.

Уся логіка (перемішування, черга, бали, ролі, збереження, Wake Lock, озвучка) — чисті функції в `src/lib/` і покрита юніт-тестами повністю. Те, що юніт-тестами не перевірити (екрани, фото через canvas, localStorage, перезавантаження, вигляд на 320 px, темна тема), покрито e2e.

## Питання

Усі питання — у `src/data/questions.json`. Після зміни файлу гра сама перевірить схему й покаже зрозумілу помилку, якщо щось не так; `npm test` перевіряє справжній файл.

```jsonc
{ "id": "gs-26",              // унікальний
  "category": "guess",        // id категорії з categories[]
  "type": "guess",            // open | choice | activity | guess | who (за замовчуванням — з meta.fieldDefaults)
  "audience": "all",          // all | kids
  "answerer": "self",         // хто відповідає: self | left | right | pick
  "about": "left",            // про кого: self | left | right | pick | answerer (за замовчуванням — про того, хто відповідає)
  "text": "Що гравець ліворуч любить найбільше?",
  "tip": "Необов'язкова підказка для дорослих" }
```

Правила тексту (їх перевіряють тести):
- **без імен** і без `{…}`: роль пишемо словами — «гравець ліворуч / праворуч», «вибери будь-кого», «той, чия черга»; ім'я й фото гра покаже над карткою;
- **без форм у дужках** на кшталт «з'їв(ла)»: про інших — у чоловічому роді («гравець не з'їв би»), до тебе — безособово («Коли тобі востаннє було весело?»);
- у guess-питанні слова мають називати, про кого воно;
- у категоріях з балами (`meta.scoringCategories`) — лише `type: guess`;
- **нічого 18+**: гра сімейна. Набори для пар, дорослих і друзів — у [docs/backlog.md](docs/backlog.md).

## Озвучка (необов'язково)

Без озвучки гра працює як звичайно: питання читає хтось із гравців. Якщо для питання є файл `public/audio/{id}.mp3`, картка читає питання сама (перемикач «Читати питання вголос»), а кнопка «Слухати» / «Стоп» повторює чи зупиняє. Генерація одноразова й пропускає готові файли.

### Gemini TTS — найживіший голос, платно (копійки) — у грі зараз

Ключ — у [Google AI Studio](https://aistudio.google.com/apikey), у `.env` (у git не потрапляє):

```
GEMINI_API_KEY=...
GEMINI_MODEL=gemini-3.8-flash-tts   # необов'язково, можна й --model
```

```bash
npm run audio -- --engine gemini --batch --force   # усі питання одним пакетом (рекомендовано)
npm run audio -- --engine gemini                   # по одному запиту — для кількох нових питань
npm run audio -- --engine gemini --batch --lang ru   # російською: тексти з src/data/packs/ru, файли в public/audio/ru
```

За замовчуванням — модель `gemini-3.8-flash-tts` і голос **Achird** (вибір 11.11); інші — `--model`, `--voice`.

Потрібна оплата (Billing в AI Studio): безкоштовно — лише 10 запитів на добу. Але й на платному Tier 1 модель 3.8 приймає **не більше 100 звичайних запитів на добу** (і кілька на хвилину — скрипт сам чекає). Тому всі питання краще озвучувати **пакетом** (`--batch`, Batch API): окремий ліміт, удвічі дешевше, зазвичай готово за кілька хвилин. Пакети йдуть частинами по 250 питань: відповідь на 900 питань одразу — понад 500 МБ, більше, ніж JavaScript може прочитати. Усі 200 питань пакетом — приблизно $0,2 (≈ 20 хв звуку, $4,5 за 1 млн звукових токенів, 25 токенів на секунду). Варто поставити ліміт бюджету. Якщо добовий ліміт вичерпано, скрипт зупиняється з поясненням, коли він скинеться; готові файли наступного разу пропускаються.

Стиль читання (`GEMINI_STYLE` у `scripts/audio-lib.mjs`) моделі 3.x отримують окремо, у `speech_metadata.style`: текст вони читають дослівно, тож інструкція в тексті прозвучала б уголос. Моделі 2.x — навпаки, беруть стиль прямо в тексті; скрипт обирає формат сам за назвою моделі.

### edge-tts — нейронний голос, безкоштовно, без ключа (запасний)

```bash
pip install --user edge-tts
npm run audio                                  # голос Поліна (uk-UA-PolinaNeural)
npm run audio -- --voice uk-UA-OstapNeural     # чоловічий голос Остап
```

Це ті самі нейронні голоси Microsoft, що читають уголос у браузері Edge: звучать природно, з правильними наголосами. Спосіб неофіційний (без ключа й договору), тож якщо колись перестане працювати — перейди на Azure F0 нижче: голоси ті самі. Якщо `edge-tts` не в `PATH`: `EDGE_TTS_BIN=~/Library/Python/3.9/bin/edge-tts npm run audio`.

### Piper — локально, але якість для української слабка

```bash
pip install --user piper-tts
mkdir -p ~/piper && cd ~/piper && python3 -m piper.download_voices uk_UA-ukrainian_tts-medium && cd -
npm run audio -- --engine piper --model ~/piper/uk_UA-ukrainian_tts-medium.onnx --speaker 2
```

Модель читає посимвольно й знає лише малі літери, тож скрипт сам готує текст (малі літери, числа словами, без лапок). WAV кодується в MP3 у Node (lamejs), ffmpeg не потрібен.

### Azure F0 — безкоштовний рівень

У `.env` (у git не потрапляє):

```
AZURE_SPEECH_KEY=...
AZURE_SPEECH_REGION=westeurope
AZURE_SPEECH_VOICE=uk-UA-PolinaNeural
```

```bash
npm run audio -- --engine azure
```

Інше: `--list` (що буде озвучено), `--force` (перезаписати все, напр. іншим голосом), `--only gs-01,gs-02`. Файли — моно MP3 48 кбіт/с (edge-tts, Azure) чи 32 кбіт/с (Piper), ~20–35 КБ на питання. Після нових питань просто запусти ще раз — готові файли пропускаються.

### Неправильні наголоси

Якщо голос наголошує слово не там, додай його в `src/data/pronunciation.json`: ключ — слово малими літерами, значення — те саме слово з наголосом (знак U+0301 одразу після наголошеної голосної, напр. `"за\u0301мок"`). Скрипт ставить наголоси перед озвученням і перевіряє словник (рівно один наголос, після голосної, те саме слово); юніт-тест теж перевіряє його. Потім перегенеруй лише зачеплені питання:

```bash
npm run audio -- --engine gemini --stressed
```

**Тиша на початку записів.** Gemini записує перед голосом 0,2–0,45 с тиші. Нові файли генератор зрізає сам; для вже готових позиція голосу лежить у `public/audio[/ru]/starts.json`, і гра стартує звідти. Перерахувати: `node scripts/audio-starts.mjs` і `--lang ru` (декодує браузер Playwright).

Якщо записаної озвучки немає, у налаштуваннях можна ввімкнути **голос браузера** — він доступний, лише якщо на телефоні є український голос.

## Встановлення на телефон

Гра — PWA: після встановлення відкривається як застосунок, без адресного рядка, і працює без інтернету.

- **iPhone (Safari):** відкрий сайт → «Поділитися» → «На початковий екран». Встановлена гра не втрачає збережених даних (Safari чистить дані сайтів, які не відкривали 7 днів, але не встановлених на екран).
- **Android (Chrome):** відкрий сайт → меню ⋮ → «Встановити застосунок» (або банер «Додати на головний екран»).

Під час гри екран не гасне (Wake Lock). Якщо телефон цього не вміє, гра підкаже вимкнути автоблокування.

## Версії

Номер версії — у `package.json` (`MAJOR.MINOR.PATCH`), опис змін — у `CHANGELOG.md` (новий розділ згори). Тест перевіряє, що `CHANGELOG.md` починається з поточної версії. Гра показує версію, дату збірки й коміт на екрані «Про гру».

Випуск: підняти версію в `package.json`, додати розділ у `CHANGELOG.md`, push у `main`. Встановлена гра побачить смужку «Є нова версія — Оновити»; збережена гра й історія не губляться.

## Приватність

Імена, фото й прогрес зберігаються лише в браузері цього телефона (localStorage). Нічого нікуди не надсилається. «Видалити всі фото» в налаштуваннях стирає фото й шаблони.

```

  data/questions.json   питання
  lib/                  логіка без Svelte (покрита тестами на 100%)
  screens/, components/ інтерфейс на Svelte 5
public/fonts/           шрифт Nunito (OFL, див. OFL.txt)
public/icons/           іконки PWA (джерело — icon.svg, PNG — npm run icons)
public/audio/           озвучка, якщо згенерована
scripts/                генерація аудіо й іконок
tests/                  юніт-тести; tests/e2e — Playwright
docs/                   roadmap і беклог
```
