# Беклог

Ідеї, які свідомо відкладені. У поточну гру не входять.

Набори питань (пари, друзі, 18+) і російська мова перенесені в роудмап, етап 12 (11.11).

## Болгарська та англійська мови

Так само, як зроблено російську: інтерфейс, усі 904 питання, правила, «Що нового» й озвучка.

- **Словники інтерфейсу.** `src/i18n/bg.js` і `en.js` (~230 ключів), мови в `LANGS` / `LANG_NAMES`, перемикач у налаштуваннях.
- **Множина.** `plural.js` зараз знає лише українські й російські форми (1 / 2–4 / 5+). В англійській і болгарській форм дві (1 / решта), тож словник має давати форми під свою мову. *Тест:* юніт на `plural` для кожної мови.
- **Питання.** `src/data/packs/bg/*.json` і `en/*.json` з тими самими id. Не дослівний переклад, а адаптація: жарти, «Цікаві факти» (перевірити, що факт правдивий і зрозумілий у тій країні), звертання на «ти», без родових форм «(ла)» (в англійській їх немає взагалі). *Тест:* як `packs-ru`: ті самі id і структура, жодного дубля, жодного українського слова.
- **Озвучка.** `npm run audio -- --lang bg --batch` і `--lang en`, по 900 файлів. Спершу перевірити, чи Gemini TTS читає болгарську; якщо ні — Azure (`bg-BG-KalinaNeural`). Англійська — Achird. Вартість — як для російської.
- **Офлайн.** Кожна мова — ще ~54 МБ, але качається лише вибрана, тож для гравця нічого не змінюється.
- **Назва гри.** «Хто є хто» → «Кой кой е» / «Who's Who» (у маніфесті назва одна — лишити українську або зробити окремий маніфест на мову).

## Застосунок у App Store і Google Play (React Native)

Мета — гра в магазинах застосунків, а не лише як сайт, який додають на екран.

- **Два шляхи.**
  - **React Native (Expo)** — переписати інтерфейс на React Native; логіку з `src/lib` (стан гри, колода, ролі, історія, перевірка питань) перенести майже без змін, вона без браузерних залежностей. Нативні звук, вібрація, «не гасити екран». Робота — кілька тижнів.
  - **Capacitor** — загорнути нинішню Svelte-гру в нативну оболонку як є. Кілька днів, ті самі тести. Для гри-розмови без складної анімації цього достатньо; React Native має сенс, якщо далі буде багато нативного (покупки, сповіщення, віджети).
- **Що потрібно для React Native.** Expo + EAS Build / Submit; `expo-audio` для озвучки (файли в застосунку або докачування набору при першому запуску), `AsyncStorage` замість localStorage, `expo-keep-awake`, `expo-image-picker` для фото гравців. *Тести:* Jest для логіки (ті самі 100%), Maestro чи Detox — для того, що зараз перевіряє Playwright.
- **Акаунти розробника.** Apple Developer — $99 на рік; Google Play — $25 один раз. Для публікації в Google Play на новому особистому акаунті потрібне закрите тестування: 12 тестувальників протягом 14 днів.
- **Вікові рейтинги.** Набір 18+ і дитячий режим в одному застосунку не поєднуються: з 18+ застосунок отримає рейтинг 17+ (Apple) / Mature (Google) і не потрапить у розділ «Для дітей». Варіанти: 18+ лише в сайт-версії; окремий застосунок для дорослих; або 18+ як покупка, що з'являється лише після підтвердження віку (рейтинг усе одно буде 17+).
- **Приватність.** Гра нічого не відправляє — у формах магазинів це «Data not collected». Якщо додати аналітику чи рекламу, це зміниться, а для дитячої аудиторії діють жорсткі правила (COPPA, Google Families).
- **Розмір.** Озвучка однієї мови ~54 МБ; з усіма мовами застосунок буде понад 200 МБ. Краще класти в застосунок лише сімейний набір, а решту докачувати.

## Монетизація: реальні варіанти

Від найреалістичнішого для такої гри до найменш:

1. **Безкоштовна гра + платні набори.** Сімейний набір безкоштовний; «Для пар», «Для друзів», «18+» і майбутні тематичні — разова покупка ($1,99–2,99 за набір) або «усе назавжди» ($5,99–7,99). Так заробляють більшість ігор-розмов у магазинах. Технічно: покупки в застосунку через RevenueCat (безкоштовний до $2,5 тис. на місяць); на сайті — Stripe чи Monobank-оплата й код розблокування.
2. **Тематичні сезонні набори.** Новий рік і Різдво, день народження, весілля, перше побачення, тімбілдинг, дорога в машині. Їх легко робити (Gemini пише й озвучує), і вони дають привід повертатися в гру.
3. **Друкована колода.** Ті самі питання — фізичні картки з QR-кодом на озвучку. Друк на замовлення (наприклад, MakePlayingCards чи українські друкарні), продаж через Etsy, Rozetka, Prom чи свій сайт. Добрий подарунок і реклама застосунку.
4. **Версія для команд і шкіл.** Набори для тімбілдингу, вчителів і психологів (знайомство класу, сімейна терапія). Продаж ліцензій організаціям — разова оплата чи річна.
5. **Свої питання (преміум).** Гравці пишуть свої картки або просять ШІ скласти набір під компанію («про нашу родину», «про весілля Олі й Тараса») з озвучкою. Цікаво, але кожна генерація коштує грошей (Gemini), тож лише як платна функція.
6. **Донати.** «Підтримати автора» (Monobank-банка, Buy Me a Coffee) — найпростіше, працює вже в сайт-версії, але приносить мало.
7. **Підписка.** Для гри, у яку грають кілька разів на місяць, люди неохоче платять щомісяця. Має сенс лише разом із регулярними новими наборами.
8. **Реклама — не радимо.** Вона ламає атмосферу гри за столом, а в дитячому режимі закон дозволяє лише сертифіковану «сімейну» рекламу. Гра зараз обіцяє «без реклами».

Що робити першим: Capacitor-збірка → магазини з безкоштовним сімейним набором → платні набори (варіант 1) → сезонні набори (2). Друкована колода (3) — паралельно, вона не залежить від коду.
