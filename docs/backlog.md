# Беклог

Ідеї, які свідомо відкладені. У поточну гру не входять.

## Набори питань (окремо від сімейного)

Кожен набір — окремий файл питань, який вибирається на екрані налаштувань. Сімейний набір лишається за замовчуванням і завжди безпечний для дітей.

- **Для пар.** Двоє гравців. Питання про стосунки, спогади, мрії, вдячність, «як ти бачиш нас через 10 років».
- **Для дорослих 18+.** Відверті питання. Видно лише після явного підтвердження «Усім гравцям є 18», і ніколи не змішуються з сімейним набором.
- **Для друзів, які зібралися.** Легкі й смішні, про спільні історії та «хто з нас найімовірніше…».

Що зробити в коді:
- вибір набору в налаштуваннях;
- окремий лічильник використаних карток і окрема історія номерів для кожного набору;
- для 18+ — підтвердження віку й заборона змішування з сімейним набором;
- у валідаторі для сімейного набору й далі відхиляти `audience: adults`.

## Російська мова

Друга мова гри поруч з українською. Українська лишається основною й за замовчуванням.

Що зробити:
- перемикач мови в налаштуваннях; вибір зберігається на телефоні;
- усі тексти інтерфейсу винести з компонентів в окремі файли перекладів (`uk`, `ru`);
- 200 питань і правила перекласти окремим файлом `questions.ru.json`, з тими самими id і перевіркою валідатором;
- окрема озвучка: `public/audio/ru/{id}.mp3`, голос Gemini (той самий скрипт, `--out` і російський текст); офлайн-завантаження — лише для вибраної мови;
- голос браузера — російський, якщо вибрано російську;
- «Що нового» й екран «Як встановити» — обома мовами.

*Тести:* юніт — у кожного ключа є переклад обома мовами, питання `ru` проходять валідатор і мають ті самі id, що й `uk`; e2e — перемикання мови змінює інтерфейс і питання, вибір зберігається після перезавантаження, кнопка 🔊 грає файл потрібною мовою.

## Питання, прибрані з сімейного набору

Підходять для набору «Для дорослих» чи «Для друзів». Готові до повернення.

{ "id": "sh-11", "category": "show", "type": "activity", "text": "Покажи свою реакцію на новину, що завтра не треба на роботу.", "audience": "adults" }
{ "id": "mm-08", "category": "memory", "text": "Яким ти був(ла) у віці дітей, що сидять поруч?", "audience": "adults" }
{ "id": "dp-01", "category": "deep", "text": "Яку пораду ти дав(ла) б собі у 18 років?", "audience": "adults" }
{ "id": "dp-04", "category": "deep", "text": "Яку рису в собі ти хотів(ла) б передати дітям?", "audience": "adults" }
{ "id": "dp-05", "category": "deep", "text": "Що тебе засмучує, але про це рідко кажуть уголос?", "audience": "adults" }
{ "id": "dp-08", "category": "deep", "text": "Яке рішення змінило твоє життя?", "audience": "adults" }
